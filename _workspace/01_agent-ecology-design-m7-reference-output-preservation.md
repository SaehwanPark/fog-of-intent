# Agent Ecology Design — M7 Reference Output Preservation

## Goal and Roadmap Milestone

- **Milestone:** M7 — Semantic-to-Parametric Calibration Proof
- **Slice:** Preserve reference outputs without storing or requiring private chain-of-thought.

## Behavioral Question and Evidence Boundary

How can observable reference decisions (intent, focus, commitment, ping signals, and structured rationales) generated by AI models under diagnostic dilemmas be captured and preserved as clean, reproducible empirical records without introducing hidden scratchpad state or requiring private chain-of-thought reasoning?

## Agent Families and Baselines

- Canonical baseline semantic profiles:
  - `cautious-laner-semantic-v1`
  - `risk-taking-laner-semantic-v1`
  - `yielding-laner-semantic-v1`
- Model families and prompt protocols:
  - `model-family-reference-v1` with `prompt-protocol-reference-diagnostic-v1`
  - `model-family-alternative-v1` with `prompt-protocol-alt-diagnostic-v1`

## Observation, Memory, and Policy Inputs

- Reference outputs are bound to:
  - `DiagnosticChoiceDefinition` / `DiagnosticDilemmaDomain` across all 7 canonical dilemmas
  - `ModelPromptProtocolDefinition` (which strictly enforces `chain_of_thought_required: false`)
  - `SemanticProfileDefinition`
- Observable outputs consist solely of:
  - `LaneIntent`: Primary or alternative strategic action
  - `LaneTargetFocus`: Minions, OpposingLaner, Tower
  - `LaneCommitment`: Standard, Cautious, Aggressive
  - `LanePingSignal`: None, Danger, OnMyWay, Assist, EnemyMissing
  - `Option<StructuredRationale>`: Categorized structured explanation (e.g. `ThreatMitigation`, `ResourcePreservation`, `ObjectiveContest`, `TeamCoordination`, `FallbackContingency`, `PacingAdjustment`) with bounded concise summary tag.

## Randomness and Reproducibility

- Canonical reference output suites are deterministic and static.
- Rejection of private chain-of-thought is fail-closed (`chain_of_thought_present == true` returns `Err(ReferenceOutputError::PrivateChainOfThoughtForbidden)`).

## Scenarios, Populations, and Metrics

- `ReferenceOutputPreservationReport` validates:
  - Exactly 7 records corresponding to the 7 canonical dilemma domains in order.
  - Zero private chain-of-thought presence across all records (`chain_of_thought_free == true`).
  - Correct matching between dilemma domain and registered choice definition.
  - Formatted Markdown rendering of reference output records.

## Expected Effects and Failure Signals

- Any attempt to instantiate a reference output record with `chain_of_thought_present == true` fails immediately.
- Unregistered profile IDs, choice IDs, or prompt protocol IDs fail closed.
- Mismatched dilemma domains fail closed.
- Overlong or empty rationale summaries fail closed.

## Verification Contract

- Unit tests in `src/agent/tests.rs` verifying all error variants, baseline suites, CoT rejection, and Markdown formatting.
- Clean format, clippy (`-D warnings`), unit test suite, and repository checks.
